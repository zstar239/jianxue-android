# Android 移植结构

`JianxueService` 负责系统输入连接和编辑器生命周期。它将触摸键与物理键转换为 JSON 事件，把返回的文本写入 `InputConnection`；输入算法、标点转换、短语匹配和候选布局都在 Rust 引擎中。

`EngineHost` 使用应用进程内的专用 `HandlerThread`，初始化资源、创建 JNI 会话、处理按键与持久化均串行执行。每个 JNI 句柄只能由创建它的线程使用，Rust panic 不穿越 JVM。引擎加载和译词查询不在主线程运行。

`native/src/session/mod.rs` 复用 Qingjian 的 `Engine`、`CandidateLayout`、字词库、语言模型、学习器、词汇本、译词和云服务模块。输入优先产生基础候选，再单独补充译词和异步整句重排。候选帧带版本号；页面点选只能提交显示时缓存的候选，过期点选会被拒绝。固定短语的空格和位置由原布局模块保留。

`SessionGuard` 将系统编辑器切换与异步回调绑定到会话代次，避免旧输入框的候选或结果写进新输入框。选区翻译另保存原选区位置与文本，用户移动选区后取消请求，接受译文时再次核对。

密码框绕过转换，直接写入系统连接。密码、手动私密输入及 `IME_FLAG_NO_PERSONALIZED_LEARNING` 都开启 Engine 私密模式；额外的 `PrivateMeter` 阻止输入统计落盘。没有接入输入日志。应用禁止备份和设备转移；密钥由 Android Keystore 加密保存。默认不创建云客户端。

正式只读资源从 APK 复制到应用私有目录，逐文件验证构建时生成的 SHA-256，完成后才写就绪标记。用户学习、词汇与导入词库单独保存在私有目录。SAF 负责用户选择的词库导入和生词本导出，不请求存储读取权限。

云联想只有用户明确启用并保存 HTTPS 服务与密钥后才可用。引擎将光标前后上下文裁剪为 64 / 32 字；选区翻译另可发送最多 2000 字的选区。网络结果不阻塞基础输入。Android HTTPS 使用 Rustls 与随依赖更新的 Mozilla 信任根，并拒绝重定向。

九键算法在 `native/src/t9.rs`。它按数字编码索引正式词库（包含已启用领域与导入词库），以归一化词频做有界路径搜索，每个位置最多保留 8 条拼音路径。`session/nine_key.rs` 将每条路径交给原 Engine，合并候选时保留对应原拼音，以实际消费字母数消费数字余码。点选仍走 Engine 的学习、统计和隐私边界。译词只补注释，不改变帧版本；展开候选保留原全局格位和帧版本。

`KeyboardView` 原生触摸界面提供九键与二十六键、候选展开和工具面板。高度只调整按键行，横屏限制高度；主题和触感是 Android 界面设置，不影响引擎配置。`JianxueService` 用串行事件先结束组句，再执行光标或剪贴板操作，避免异步组句覆盖用户选区。

剪贴板不注册后台监听器，不读取 URI 或 Intent。只在用户打开面板时读取纯文本，跳过敏感标记与超过 4000 字的内容。最多保留 20 条内存记录，只有手动收藏会用 Keystore AES-GCM 加密落盘；进入私密输入清除内存记录，面板只提供系统粘贴按钮。表情最近使用只记表情，不在私密输入中更新。
