# 移动端使用说明

安装后在系统启用简学并选择键盘。首次加载正式词库和模型稍等片刻。默认中文为九键拼音；密码、网址、邮箱和英文使用二十六键，数字、电话与日期字段使用数字键盘。

## 九键与候选

- 按手机字母分组输入：2 ABC、3 DEF、4 GHI、5 JKL、6 MNO、7 PQRS、8 TUV、9 WXYZ。
- `64426` 对应 `nihao`，点「你好」或空格上屏；`52432` 对应 `kaifa`，可选「开发」。
- 左栏显示首音节，点 `ni` 等拼音可消歧；「重选」解除锁定。可连续输入多音节，选择前半段汉字后保留未消费的数字。
- ‹ / › 翻页，⌄ 展开候选。长按候选可输入译词或清除个人用词记录；一次只显示一种学习语言。
- 删除键长按连续退格。回车在组句中输入原文（九键为数字），组句完成后执行发送、搜索、换行等输入框操作。

左上角 ☰ 的「9 / 26 键」切换布局；二十六键底栏也有切换按钮。双拼、五笔与注音使用二十六键；切到九键会选择全拼。中 / EN 切换语言，长按该键显示系统输入法选择器。

## 常用工具

- **剪贴板**：点击 ▣ 查看当前纯文本和本次键盘使用的最近记录，点条目粘贴。长按可收藏、取消收藏或删除；「清空历史与收藏」清除应用的记录，系统剪贴板仍由 Android 管理。收藏最多 20 条，以 Keystore 加密保存。敏感标记和超过 4000 字的内容不会加入历史；没有后台采集。私密模式不显示历史，只提供系统粘贴。
- **表情**：点击 ☺，按表情、手势、生活、符号分类选择；「最近」保留最多 24 个用过的表情。私密模式不更新最近使用。表情样式取决于手机系统字体。
- **符号 / 数字**：底栏「符」打开基础符号，工具面板中有更多中文标点、数学、货币与单位符号，以及独立数字键盘。
- **光标编辑**：空格左右滑动移动光标；工具面板支持四向移动、行首 / 行尾、全选、复制、剪切与粘贴。移动前结束当前组句，原始输入会保留；密码禁止复制、剪切。
- **翻译选区**：先在编辑器选中文字，再点工具中的「翻译选区」，需自行启用云接口。点击返回译文替换选区；选区变化会取消。

## 外观与隐私

工具中的「主题与高度」可选择系统 / 浅色 / 深色，紧凑 / 标准 / 加高及触感开关。应用「输入」设置可把按键高度调到 40–64 dp；横屏自动收紧。触感遵循系统设置。

键盘右上角切换私密输入。密码及系统禁止个性化学习的字段自动私密：不保存词频、统计、生词或剪贴板历史，不发云请求。默认云功能关闭。语音、手写和滑行输入尚未实现。
