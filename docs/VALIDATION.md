## 0.2.0-dev 功能交互回归记录

验证日期：2026-10-04。此记录针对 **0.2.0-dev** 开发预览版，不代表全部手机与编辑器兼容。

| 检查 | 结果 |
| --- | --- |
| ARM64 / x86_64 原生 release 编译 | 通过 |
| Rust 格式、Clippy（警告视为错误）及真实引擎回归 | 17 项通过 |
| Android Java 单元测试 | 7 项通过 |
| Android debug APK / androidTest 构建 | 通过，versionCode 2 |
| Android lint | No issues found |
| 真实 JVM 加载 JNI、正式资源与模型 | 通过；含九键「你好」和连续「我想学习」候选 |
| ELF 与 APK ZIP 的 16 KB 页对齐 | 两种 ABI 均通过 |
| Cargo.lock 与第三方源码包校验 | 330 个注册表依赖通过 |
| Android 11 系统输入连接及触摸交互 | 8 项通过，AndroidJUnitRunner 报告 OK (8 tests)，105.486 秒 |
| 真实云服务 | 未提供服务凭据，未做端到端请求测试 |

新增 Rust 回归覆盖数字到真实汉字候选、点选前缀后保留数字余码、拼音消歧、过期候选拒绝、末键删除、切换模式与编辑器、私密输入不改统计，以及 125 键歧义搜索的有界性。原候选译词、固定短语、算式、Unicode、词库导入和持久化回归继续通过。

JNI 使用正式 data-v3 与含章·通变 small，实际验证 `64426 → 你好`、`969426498394 → 我想学习`，以及译词、过期帧和线程归属。主机 debug 首次九键完整转换含构建索引的一次测量为 312 ms；这不是手机性能基准。

设备使用本项目独立 Android 11 x86_64 软件模拟器，无 KVM。为降低绘图负担，将测试画面调整为 720×1520、280 dpi。设备用例实际点击九键、展开候选、点选「你好」、切换二十六键，并验证剪贴板粘贴、表情输入、选区复制和按 Unicode 字符移动光标。还验证密码直输、禁止个性化学习、末键退格及 TLS 客户端初始化。TLS 用例不发送任何请求或输入文字。

剪贴板安全用例使用真实 Android ClipboardManager 和 Keystore：敏感标记文本不会进入历史，收藏密文不含原文，新实例能解密读取，清空后删除持久化数据。

首次设备尝试在安装前遇到模拟器系统输入服务尚未就绪；下一轮又被 **System UI** 的启动无响应弹窗阻挡，前三个用例未能取得窗口焦点。已保留失败日志和真实弹窗截图，处理系统弹窗后，重新运行全部 8 项用例均通过。没有将这些失败记为成功，也没有屏蔽应用自身的错误。

最终报告在 `dist/instrumentation.txt`；首次失败和上一版报告位于 `dist/diagnostics/`。APK 使用开发调试签名，正式资源、JNI 导出、证书一致性和 16 KB 布局已核验。当前未连接物理手机；16 KB 布局检查不等于 16 KB Android 实机验证。厂商窗口差异、其他编辑器、语音 / 手写需求及用户配置的真实云服务仍需后续验证。
